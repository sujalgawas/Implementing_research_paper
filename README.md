# Implementing Research Papers

PyTorch implementations of influential Transformer and language-model papers, built for learning and experimentation.

## Implementations

- [Attention Is All You Need](./Attention%20is%20all%20you%20need/) — encoder-decoder Transformer for translation.
- [BERT](./BERT/) — bidirectional Transformer encoder for masked language modeling.
- [GPT-1](./GPT-1/) — decoder-only Transformer for autoregressive language modeling.
- [GPT-2](./GPT-2/) — improved decoder-only language model with byte-level BPE.
- [RoPE](./ROPE/) — GPT-2-style model with Rotary Position Embeddings and Pre-LN.
